# 二创加工规则细则（体检与改笔标准）

> 来源：viral-script-writer（6法则+8点钩子清单+EDIT模式）实测方法论 + 创作大师提示词去AI味规则 + viral-video-analyzer 调研结论（数字锚点不动）。全部经实战验证。

## 一、钩子8点清单（首句体检标准）

首句必须全部通过：
1. **独立成立**：无悬空指代，脱离上下文也能看懂（发布后首句直接用作视频标题）
2. **具体冲突/关键词**：含可搜索词、具体数字或具体场景，不用反讽绕弯
3. **人类口语测试**：真会这么说吗？读出来别扭就重写
4. **标题测试**：首句是不是直接就是发布标题？不是就重写
5. **好奇债务测试**：正文中至少一个未闭合悬念保持到结尾；长文拆集时上集结尾必须留悬念
6. **断言式**：直给「谁吃亏/谁作恶/什么代价」，不问「你知道吗」
7. **禁问候开头**：禁「今天聊聊」「大家好」类零信息开头
8. **数字反差优先**：历史数据证明数字悬念钩最强（跳出率30.66%历史新低来自「每月3000，35岁只有45万，40岁却摸到80万」）

## 二、病毒脚本6法则（写与校验共用）

1. **首词法则**：第一句必须制造前进动力
2. **好奇债务法则**：见上第5条
3. **身份镜像法则**：至少一处让目标观众觉得「这是拍给我的」——用**具体场景点名**（「44岁社保涨到一万八你没在意」），禁人群泛化（「所有中年人都…」）
4. **自我绕过法则**：价值传递不触发「这是广告/说教」防御；禁「别总/不要/不该」教育式开头
5. **已赚CTA法则**：先给足价值再要互动；互动提问必须具体、观众能一秒回答（「换你，是60岁提前领还是硬撑到63？」）；CTA是收据不是命令
6. **恒定价值法则**：每行都要有观众不知道的东西；纯复读情绪、纯复述前文的行删除或重写

## 三、10个内容原型（C档复刻时识别原文属于哪类，复刻后保持同型）

清单体 / 辣评体 / 前后对比 / 反转故事 / 破除迷思 / 教程 / POV（第二人称模拟体）/ 反应解说 / 内幕揭秘 / 挑战实验。
每个原型配3个锁定钩子模板；数字反差模拟体（如「100万躺平模拟」）属 POV+前后对比复合型，**数字时间线本身就是故事骨架，复刻时数字锚点不动、只重写表达**。

## 四、数字核实方法

1. 列出原文全部数字，逐个演算：本金×利率、年限推演、余额轨迹、政策引用（退休年龄/社保年限/倍数标准以最新政策为准）
2. 演算不成立的给出正确值并改稿（案例：原作「月存3000年化5%十年到80万」不成立，正确为35岁约45万、40岁约78万，改后反而更呼应「回报塞最后几年」论点）
3. 核实过的数字锚点不动；模拟体的关键反差点（如「100万买来21年不用早起」）由数字自然推出，不得硬凑
4. 法条/政策类引用标注「发布前人工核对」

## 五、去AI味规则（创作大师提示词）

**禁**：
- 别总/不要/不该 教育式开头；其实/真正/说白了+抽象结论；以前/后来/现在 排比感悟；只要…就…；众所周知/毋庸置疑/深刻揭示/生动展现/让我们/不妨/倘若；排比超3句
- 元叙述（「这条视频告诉大家」「接下来我们讲」）；结尾升华总结句
- 为反差硬凑倒装对仗；无端指责观众

**荐**：
- 说白了/你想想/讲真/我跟你讲；短句≤15字；口语不完整句；像朋友聊天
- 自然语序优先；原话推动场景（同一件事的前后言行构成反差）
- 理论可选且须准确匹配、有信息增量；建议必须对应前文问题

## 六、分级加工细则

- **A档**：体检五项全过才允许A档。只动错别字/标点/转写错误，逐处报告。
- **B档（EDIT模式）**：逐行诊断只改弱句不动结构。弱句=AI味命中行、恒定价值不达标行、首句不达标。改完通读一遍确认连贯。
- **C档**：观点可借、表达必须重写（不逐句翻译，换讲法换例子换比喻）、故事全换（数字模拟体的时间线骨架除外——那是数字锚点）、首句改冲突钩。复刻稿**不声明原创**，来源登记在选题池col3备注。
- 任何档位都禁止：无依据猜恶意、泛化同事/老板/人群、万能换钱结尾、凑字数。

## 七、交付物清单

1. 完整口播正文（唯一主体，不是建议列表）
2. 体检报告：查重/首句/数字/字数/AI味/转写修正，逐项结论
3. 发布元信息：首句兼标题、描述（≤50字，公式=首句冲突+次句代价或互动+#标签）、10个标签无分号
4. 改动清单（A/B档逐处，C档列重写要点）
