# 知识库笔记模板与规范

> Obsidian 特有语法（wikilink/embed/callout/property 等）见 `references/obsidian-syntax.md`（吸收自 Obsidian 官方 agent skills），写笔记时按该规范保证渲染正确。

## 标准笔记结构

```markdown
---
title: 笔记标题
created: 2026-08-13T10:00
updated: 2026-08-13T10:00
author: 用户
tags: [主题, 类型]
source: 对话抽取
status: active
---

# 笔记标题

一句话定义或结论（让读者 3 秒抓到核心）。

> [!tip] 核心要点
> 关键结论用 callout 高亮，方便扫读。

## 展开
正文内容。用 `[[双链]]` 关联其他笔记，用 `#标签` 辅助归类。
- 要点一
- 要点二

## 相关
- [[相关笔记A]]
- [[相关笔记B]]
```

## frontmatter 字段

| 字段 | 说明 | 示例 |
|------|------|------|
| title | 笔记标题（与文件名一致） | `护城河` |
| created | 创建时间 ISO | `2026-08-13T10:00` |
| updated | 最近修订时间 | `2026-08-13T14:30` |
| author | 提供/整理者（必填） | `用户` / `张三` / `巴菲特(摘录)` |
| contributors | 修订者列表（update --by 自动维护） | `[用户, AI]` |
| tags | 1-3 个标签，复用已有优先 | `[价值投资, 概念]` |
| source | 来源 | `对话抽取` / `用户口述` / `外部资料` |
| status | 状态 | `active` / `outdated` / `draft` |

## 命名规范
- 概念用名词：`护城河`、`安全边际`
- 事件/日志带日期：`2026-08-13 投资日志`
- 案例带主体：`贵州茅台分析`
- 文件名 = title，避免特殊字符 `\/:*?"<>|`

## 双链规则
- 每条新笔记至少链 1 条相关旧笔记（MOC 或同主题）
- 用 `[[笔记名]]` 或 `[[笔记名|显示文本]]`
- 在「相关」段集中放，正文中也可自然嵌入
- 孤立笔记是债务：定期跑 `kb_ops.py backlinks` 查孤立笔记并补链

## 标签体系（建议）
- 领域：`#投资` `#技术` `#工具` `#工作`
- 类型：`#概念` `#SOP` `#案例` `#日志` `#MOC`
- 状态：`#草稿`（用 frontmatter status 更佳）

## 敏感信息红线
密钥 / token / 密码 / AppID 明文 —— 绝不写入 vault。需要记录"如何配置"时只写步骤与占位符，不写真值。
