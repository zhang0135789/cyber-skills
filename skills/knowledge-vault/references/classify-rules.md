# 自动归类体系（classify-rules）

`kb_ops add` 无 `--dir` 时，按标题+正文关键词自动决定笔记的**目录 / 标签 / 挂哪个 MOC**。规则在 `scripts/kb_ops.py` 的 `CLASSIFY_RULES` 里，可自行增改。

## 归类规则

| 主题 | 目录 | MOC | 标签 | 关键词（命中任一即归类） |
|------|------|-----|------|------------------------|
| 数字人 | `数字人/` | 数字人-MOC | 数字人 | 数字人, avatar, 虚拟人, 虚拟形象, digital human |
| 视频生成 | `技术类/视频/` | 视频生成-MOC | 技术,视频生成 | 视频生成, 文生图, 文生视频, video, diffusion, tts, 图生视频, 选型 |
| 金融投资 | `金融类/金融案例/` | 投资研究体系 | 投资 | 投资, 股票, 基金, 财报, 估值, 持仓, 护城河, 安全边际, 房产, 个税, 茅台, 价值投资 |
| 传统文化 | `文化类/` | 文化-MOC | 文化 | 中医, 易经, 八字, 命理, 调鼎集, 六十四卦, 辨证, 少阴 |
| 工具方法 | `工具/` | 工具箱 | 工具 | 工具, skill, 技能, obsidian, deeptutor, 提示词, 方法论, 知识库, mcp |
| 运营 | `运营/` | 运营-MOC | 运营 | 运营, 排期, 爬取, 视频号, 抖音, 读书号, 涨粉 |
| 日志 | `日志/` | （无） | 日志 | 日志, 日报, 周报, 复盘 |
| 技术部署（兜底） | `技术类/` | 技术类-MOC | 技术,部署 | 部署经验, 部署, 环境配置, wsl, docker, 安装, 启动, 配置 |

## 匹配优先级

1. **具体主题优先**：数字人/视频生成/金融/文化/工具/运营/日志 任一命中 → 采用该主题
2. **技术部署兜底**：具体主题都没命中，但有部署/配置类词 → 技术类
3. **未分类**：都没命中 → 根目录 + `未分类` 标签

## 梳理已有笔记

```
python scripts/kb_ops.py organize          # 预览根目录散乱笔记的归类建议
python scripts/kb_ops.py organize --apply  # 实际移动到对应目录 + 补标签/MOC双链
```

## 自定义

改 `scripts/kb_ops.py` 里的 `CLASSIFY_RULES`：增删主题、调关键词、改目录/MOC/标签。改完 `kb_ops classify "<文本>"` 即可验证。

> 归类是辅助，不是强制。`add --dir <目录>` 可手动覆写；AI 在工作流里也可调整归类建议。
