# 买入前 Checklist（六关 + 否决红线）

目标：**排除坏选择**，不是挑好选择。C 级公司"数据不足"≠"不通过"，诚实标"灰色地带，需一手验证"。

## 六关

### 第一关：能力圈——我能理解这门生意吗？
- [ ] 一句话说清靠什么赚钱
- [ ] 10 年后大概率还在做什么生意
- [ ] 认知来自深度研究还是道听途说

### 第二关：盈利能力——钱是怎么赚的、赚得稳吗？
- [ ] ROE 5-10 年趋势（>15% 且稳定）
- [ ] 毛利率/净利率水平与同行对比
- [ ] 自由现金流为正、可持续

### 第三关：财务健康——会不会暴雷？
- [ ] 负债率合理，无短期偿债压力
- [ ] 现金储备 > 净债务（净现金）
- [ ] 无会计异常（应收激增/存货积压/商誉过大）

### 第四关：估值——贵不贵？
- [ ] PE/PB 与自身历史、同行对比
- [ ] 反向 DCF：当前价隐含了什么增长预期，合理吗？
- [ ] 用工具验算，禁止心算

### 第五关：护城河——凭什么赚钱不被抢？
- [ ] 五类护城河（品牌/转换成本/网络效应/规模/技术）至少一类明确
- [ ] 护城河趋势：变宽还是变窄

### 第六关：风险——最坏情况能接受吗？
- [ ] 列出失败路径与概率
- [ ] 最大风险是否在能力圈内可管理

## 8 条否决红线（一票否决）
1. 财务造假嫌疑 / 审计保留意见
2. 大股东/管理层掏空、利益输送
3. 商业模式靠烧钱续命、无盈利路径
4. 依赖单一客户/供应商且无议价权
5. 核心业务被技术/政策颠覆且无应对
6. 管理层劣迹（造假、套现跑路、诚信污点）
7. 估值远超内在价值且无安全边际
8. 看不懂（5 句话说不清生意）——"镜子测试"：5 句说不完整 = 不买

## 评分输出
每关 ★1-5 + 总评：**通过 / 不通过 / 灰色地带**（灰色地带 = 数据不足或矛盾，需一手验证，不勉强判）。
